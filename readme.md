# おかね ぴったり げーむ 🪙

小学生低学年向けのお金計算練習Webアプリです。
指定された金額になるように、コインをお皿に集めて遊びながら楽しくお金の計算を学べます。

## 特徴
- 1円、5円、10円、50円、100円、500円の硬貨を使って計算を練習できます。
- タッチ操作に完全対応しており、スマホやタブレットでも直感的に遊べます。
- 間違えても「あと〇〇えんたりないよ」「〇〇えんおおすぎるよ」とヒントが出るので、自力で計算をやり直す力が身につきます。
- 漢字を使わず、ひらがなを中心としたやさしいデザインです。

## 遊び方
1. 画面の上に表示された「〇〇えん にしてね！」の目標金額を確認します。
2. 画面に散らばっているコインを指（またはマウス）でドラッグして、中央の白い「おさら」に乗せます。
3. お皿の上の金額がぴったりになったと思ったら、赤い「せいさん」ボタンを押します。
4. 全部で5問。だんだん難しくなる問題にチャレンジしよう！
